# 📚 Dates - Année Scolaire

Suis ta progression dans l'année scolaire en temps réel.

🔗 **Démo :** https://fozyllll.github.io/Dates/

## ✨ Fonctionnalités

- 📊 Pourcentage de l'année écoulée en temps réel
- 🗺️ 5 régions : FWB, Flandre, France, Québec, Suisse + dates perso
- 🎉 Fêtes par région avec compte à rebours
- ⭐ Événements personnels sauvegardés
- 🏖️ Mode vacances automatique avec compte à rebours de reprise
- ⏳ Widget prochaine fête
- 🌙 Thème sombre / clair
- 🔔 Notifications la veille des fêtes
- 📤 Partage sur WhatsApp

## 🚀 Utilisation

Ouvrez simplement https://fozyllll.github.io/Dates/ dans votre navigateur.
Aucune installation requise.

## 🛠️ Tech

HTML / CSS / JS vanilla - 100% statique, données en localStorage.
